# 手动导出雪球 Cookies 方法

## 方法1: 使用浏览器扩展
1. 安装 Chrome 扩展 "Cookie-Editor"
2. 访问 https://xueqiu.com 并登录
3. 点击扩展图标 → "Export" → 复制 JSON

## 方法2: 使用开发者工具
1. 登录 https://xueqiu.com
2. 按 F12 打开开发者工具
3. Application → Cookies → https://xueqiu.com
4. 复制所有 cookie 值

## 保存位置
将 cookies 保存到:
`/Users/wangguangchao/code/langchain_financial/xueqiu-analyzer-skill/config/cookies/xueqiu.json`
